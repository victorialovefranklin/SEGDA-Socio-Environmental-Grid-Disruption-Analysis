# SEGDA: Socio-Environmental Grid Disruption Analysis

**A Multi-Scale Spatial Assessment of Energy Justice and Climate Resilience Across California Census Tracts and Counties, 2018–2023**

**Author:** Victoria Love Franklin  
**Conference:** EAI SmartGIFT 2026  
**Status:** Accepted for presentation and publication in the proceedings workflow

SEGDA is a reproducible, multiscale geospatial framework integrating environmental justice, reconstructed electricity-outage exposure, climate stress, and social vulnerability across California census tracts and counties.

## Conference

Official EAI SmartGIFT 2026 accepted-papers page:

## Repository contents

- `src/segda.py` — audited SEGDA analysis and camera-ready visual pipeline.
- `requirements.txt` — Python dependencies used by the script.
- `docs/methodology.md` — summary of the locked analytical method.
- `docs/data_sources.md` — required input files and redistribution guidance.
- `docs/reproducibility.md` — instructions for running the pipeline.
- `figures/` — place publication figures generated by the pipeline here if you choose to version them.
- `results/` — place nonrestricted derived results here if you choose to version them.
- `CITATION.cff` — citation metadata for the repository.
- `.gitignore` — excludes common local, generated, and sensitive files.

## Key audited results

The script contains guardrails for the locked camera-ready results, including 8,057 tract geometries, 7,931 strict EJBI tracts, 1,690 High-EJBI tracts, 58 counties, 11 High-EJBI counties, 67.82% tract-to-county variance suppression, and 431 High-EJBI tracts masked by county aggregation.

## Data availability

The repository does not redistribute the required source datasets by default. Users should obtain source data from the authoritative providers and place the required files in a local data directory. See `docs/data_sources.md`.

## Running SEGDA

```bash
python -m pip install -r requirements.txt
export SEGDA_DATA_DIR=/path/to/segda/data
python src/segda.py
```

On Windows PowerShell:

```powershell
$env:SEGDA_DATA_DIR="C:\path\to\segda\data"
python src\segda.py
```

The script creates its own organized output directories and an export ZIP after a successful run.
